# Security Policy

## Supported Versions

Only the latest commit on the `main` branch is actively supported.

## Reporting a Vulnerability

If you discover a security issue in Talos, **do not open a public issue**.  
Instead, please report it privately using one of these methods:

- **GitHub Private Vulnerability Reporting**: Go to the **Security** tab → **Report a vulnerability**.  
- **Email**: [ddemmc@gmail.com]

I will acknowledge your report within 48 hours and work with you on a fix.

## Scope

This policy covers the code in this repository, including the Python modules, installers, and any bundled scripts. It does **not** cover third‑party dependencies (though I monitor them via Dependabot).

## Ethical Use

Talos includes offensive‑security modules (HTTP brute‑force, Metasploit runner, Nmap scans).  
**Use only against systems you own or have written permission to test.**  
I will not assist with or condone unauthorised use.
